# やまだ商店 AI経営 ── 何ができるか（2026-11-10）

架空の会社「株式会社やまだ商店」を、**人のオーナー1人と AI の組織**で回すサンプルです。
Claude Code で動きます。データは全部架空です（本物の会社・人・お客さんは出てきません）。
AI道場の動画で、AIエージェントの実演に使い続けるための「サンプル企業」です。

印の意味：✅ 実際に動かして確かめた ／ 🟡 作ってあるが、まだ通しで確かめていない

**2026-11-10 に本格版ができ、5分のデモを Claude Code で通しで確かめた（合計 1分45秒）。**

---

## 1. ひとことで

「やまだ商店の売上どうやった？」と聞くだけで、**AI社長が部署の AI に仕事をふり、全社の報告と「今日やること3つ」「社長の承認が要るもの」を返す**会社です。
AI は調べて・まとめて・提案するところまで。**お金が動くことと、外への約束は、人（山田社長）が決めます。**

## 3. いまできること

### 3-1. 全社の報告 ✅（2026-11-09 に確かめた）

聞くこと：**「やまだ商店の売上どうやった？」**

返ってきたもの（実際の結果の要約）：

- AI社長が7つの部（店長・仕入れ・経理・EC・接客・法務・営業）を同時に呼んだ。
- 部どうしの話を1本につないだ：**「定期発注の抜け → 人気の地ビールが欠品 → 店の酒類が急落 → ネットで売り越し6件 → 口コミが3件」**。
- 全体の数字（先月 479.7万円・前年比 +0.2%）、事業別の表（法人は粗利率18%で最も低い）、各部の気づき。
- 今日やること3つ：①地ビールを今日15時までに発注（秋祭りに間に合う最後の便）②ネットの在庫表示を直して未出荷の6件に連絡 ③入金が遅れている居酒屋への方針を11/30より前に決める。
- 承認が要るもの：発注の金額・期限つきで一覧に。

かかった時間：最初は11分33秒 → 本格版で **67〜79秒**（11/10。AI社長は4部だけを並行で呼び、各部は集計の道具 `tools/q.py` を1回使う）。
承認が要るものは、期限の近い順に**上位5件だけ**を出す（残りは `/承認待ち`）。

### 3-5. 会社が1日ずつ進む（シミュレーション） ✅

- `/一日進める` で翌日の営業が起きる：欠品なら売れない・発注は納期の後に届く・秋祭りは売れる・雨の日は配達が増える・入金と支払い・月末の締め。
- 同じ日付と同じ状態なら、毎回同じ結果（撮り直しても数字が変わらない）。
- 自動で発注する仕入れ先は、行事の分まで前もって見込む。承認が要るのは播磨麦酒・日用品卸・包装だけ。
- 撮り直す前に `python3 tools/sim.py init --clean` で、11/10（火）の朝に戻る（承認とログも空に）。

**確かめた流れ（11/10）**：播磨ゴールドの発注だけを承認 → 5日進める → 11/13 に95パック入荷・ネットで待っていた8件を出荷 → 11/14 の秋祭りで酒類 117,730円 → 欠品は承認しなかったティッシュだけ。

### 3-6. 安全の決まり ✅

- AI はデータを**読むだけ**。書いてよいのは `reports/`（レポート）・`approvals/pending/`（提案）・`logs/` だけ。
- データのファイルは読み取り専用。AI が Python で書き換えようとしても止まる（テストで確かめた）。
- 会社を進める・承認を反映するのは、人がコマンドを打った時だけ。承認していない提案は反映されない。
- 発注・値下げ・広告費・支払い・督促・契約・お知らせの公開・SNS・口コミの返信は、全部【要承認】で社長に出す。**AI は送らない・頼まない・払わない。**
- 社名はひらがなの「やまだ商店」。お客様個人の名前・住所・電話は書かない。

## 5. 動画での使い方

**第2話（AIエージェントの作り方）**：エージェントを1つ作る実演の舞台。最後に「全部やるとこうなる」として、この組織を見せる案。

**これからの回の案（1つの部署＝1本）**：

| 回の案 | 主役の AI | 見せ場 |
|---|---|---|
| 入金が遅れている取引先、AI に見つけさせたら | AI経理 | 期日を過ぎた売掛金 → 督促の下書き → 社長が承認 |
| 契約の更新、AI に見張らせたら | AI法務 | 自動更新の期限・お酒の表示漏れを見つける |
| チラシとインスタ、どっちが儲かる？ | AI広告 | 粗利で見るとチラシは赤字 |
| 秋祭りに間に合う発注を AI に | AI仕入れ | 納期から逆算して「今日15時が最後」 |
| ネットの売り越しを AI が止める | AI EC販売 | 在庫表示のずれを見つける |
| 口コミの返信を AI に下書きさせたら | AI接客 | 低い評価への返信の型 |
| AI に1週間、会社を任せてみた | AI社長と全員 | 1日ずつ進めて、承認して、数字が変わる |
| 月次決算を AI で | AI経理 | 予算・前年と比べた月次の報告 |
