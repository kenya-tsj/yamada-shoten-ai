# シミュレーションの決まり（tools/sim.py）

※架空の会社のための、わざと単純な決まりです。説明できて、毎回同じ結果になる（決まった乱数の種＝日付）ことを優先しています。

## 動かし方

| コマンド | すること |
|---|---|
| `python3 tools/sim.py init [--date YYYY-MM-DD]` | はじめの状態に戻す（既定 2026-11-10・火）。2年分の歴史を作り、直近8週＋先月から今日までを data/ に書く |
| `python3 tools/sim.py advance --days N` | 会社を N 日進める（今日の分の営業を1日ずつ回す）。data/ に行を足し、派生のファイルを作り直す |
| `python3 tools/sim.py apply <ID>` | `approvals/approved/` にあり「## 決定」に承認の記録がある提案だけ、効果を会社に入れる（二重には入れない） |
| `python3 tools/sim.py status` | 今の会社を10行で |

- 1日 ＝ 朝（入荷・ネットの未出荷を出す・生ものの定期）→ 営業（店・配達・ネット・ギフト・法人）→ お金（入金・25日の給料・月末の支払い）→ 夜（定期の自動発注）。
- 乱数の種は「20261109-日付」。同じ状態から同じ日を進めると、必ず同じ結果。
- 書き終わると data/ と sim/state.json は読むだけ（書き込み不可）になる。

## 売れ方

- 数はすべて「単位」で数える（`data/master/商品.csv`。例：播磨ゴールドは6缶入りのパック）。
- 商品ごとの1日の売れ数 ＝ 平均（平日）× 曜日（月0.95〜土1.25）× 月の季節 × 雨（0.88）× 値段の効き × 行事 × 広告の効き。±15% のばらつき。
- 定期（自動）の発注：毎晩、在庫＋入荷待ちが「入荷の日までの見込み＋2日分」か発注点を下回ったら、入荷のあと7日分まで頼む。見込みには地域の予定の行事（倍率・屋台）も入る。承認がいるのは播磨麦酒・◯◯日用品卸・◯◯包装だけ。
- **在庫が無ければ売れない**（売れなかった分は「欠品で逃した売上」）。毎日の生もの（パン・牛乳・卵・豆腐・納豆・青果・肉・魚）は毎朝そろう。惣菜・お弁当・おにぎりは店で作る（作る数＝見込み×1.03。売れ残りは廃棄）。
- 播磨ゴールドが無い日：大手のビール +8%・ハイボール +5%・ほかのお酒 −7%（地ビール目当ての人が来なくなる）・客数 −4%。
- **行事（秋祭り）**：酒類と飲料が 1.9倍（告知を出していれば 2.1倍）。屋台の分（播磨ゴールド 25パック、告知ありなら30）・ラムネ 40本・地酒 6本を足す。客数 1.3倍。
- 雨：店の来店 −12%、配達の注文 1.55倍、取れなかった電話は1日 約5件（ふだん 約0.7件）。
- ネット：1日 約3.4件（土日 +15%）。在庫が無くても、サイトに在庫が出ていれば注文を受けてしまい「未出荷」になる。入荷の朝に先に出す。
- ギフト：お歳暮 10/20〜12/25（山は11月下旬〜12月上旬）、お中元 6/10〜7/31。
- 法人：決まった曜日に「1回の目安」×（±10%）。居酒屋と焼き鳥は12月 +25%。

## お金

- 店・配達・ネット・ギフトはその日に入金。法人は月末締め翌月末払い（居酒屋 千鳥足は遅れる：期日を過ぎると1日2%の確率で一番古い分だけ入る）。
- 25日に給料（月90万円＋7月・12月の寸志＋シフトの上乗せ）。月末に、先月の仕入れ（買掛金）・今月の経費・借入金の返済（10万円）。
- 仕入れ（買掛金）＝その日の売上原価を仕入先ごとに積む（在庫の増減は小さいので省く）。
- 月末の夜に月を締める：法人に請求・月次PL・法人売上_月別・広告の行を足す。

## 承認の効果（apply）

| 種類 | 実行の書き方 | 会社で起きること |
|---|---|---|
| 発注 | `{"発注": [{"商品ID": "S01", "数量": 80}]}` | 今日発注。播磨麦酒は3営業日後、ほかは納期の日の朝に入荷 |
| 値下げ | `{"値下げ": [{"商品ID": "F05", "率": 0.1, "日数": 7}]}` | その日数だけ値段が下がる。売れ数 ＝ 1＋1.5×値下げ率（10%引き→+15%） |
| 広告 | `{"広告": {"チラシの回数": 1, "Instagram広告": 31000}}` | 配分が変わる。店の来店 ＝ 1＋0.006×(チラシの回数−2)＋0.002×(Instagram−12,000)/10,000、ネット ＝ 1＋0.05×(Instagram−12,000)/10,000。Instagram は増やすほど1円あたりの反応が下がる（0.8乗） |
| 督促 | `{"督促": {"取引先ID": "C01"}}` | 翌日から、期日を過ぎた分がまとめて入る確率が1日45%に上がる |
| 出荷停止 | `{"出荷停止": {"取引先ID": "C01", "止める": true}}` | その取引先への定期配達を止める（再開は false） |
| 契約・法人 | `{"契約": {"相手": "あおぞらの家", "内容": "…"}, "法人": {"C05": {"曜日": [0, 3], "1回の目安": 9500}}}` | 契約の状態が変わる。定期配達の曜日と1回の目安が変わる |
| 掲載 | `{"掲載": {"題": "…", "出した場所": "…", "行事": "秋祭り"}}` | お知らせに載る。行事の告知が「済み」になり、当日の倍率が +0.2・屋台 +5パック |
| シフト | `{"シフト": {"雨の日の午前の電話番": true}}` | 雨の日の取れなかった電話が 3割に。雨の営業日1日ごとに人件費 +4,000円 |
| シフト | `{"シフト": {"夕方のレジを2人に": true}}` | 金・土の「レジ待ち」の口コミが出なくなる。金・土1日ごとに人件費 +3,200円 |
| 配達 | `{"配達": {"北地区を午後便にまとめる": true}}` | 北地区は午後便になり、1件 約18分→約14分 |
| 在庫連動 | `{"在庫連動": true}` | サイトの在庫が毎日、実際の在庫にそろう（無い物の注文を受けない） |
| 表示 | `{"表示": {"G02": "○"}}` | 商品ページの「20歳未満」の表示が ○ になる |
| 返信 | `{"返信": "全部"}` | 未返信の口コミが「返信済み」になる |
| ページ改善 | `{"ページ改善": true}` | ネットの注文とネットのギフトが +5% |

`実行` が無い提案は、記録（施策）だけ残る。
