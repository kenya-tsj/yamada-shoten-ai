# 承認の提案の書き方（テンプレート）

AI が提案を出すときは、`approvals/pending/YYYYMMDD-NNN_件名.md` にこの形で書く。くわしい決まりは `knowledge/共通/承認の書き方.md`。
このファイル自体は提案ではない（`approvals/` の直下なので一覧に出ない）。

```
---
id: 20261110-251
件名: 播磨ゴールドと地ビールセットの発注
種類: 発注
担当AI: ai-shiire
金額: 107000
期限: 2026-11-10 15:00
効果の見込み: 11/13（金）に入荷。11/14（土）の秋祭りで酒類の売上を取り逃がさない（去年の屋台は約25パック）
根拠:
  - data/purchasing/在庫.csv S01 在庫0・発注点20
  - data/pr/地域の予定.md 11/14 秋祭り・屋台
  - data/master/仕入先.csv 播磨麦酒 3営業日・平日15時締め
リスク: 祭りのあとに売れ残る（賞味期限は約6か月なので、ふだんの週に売り切れる量にした）
実行: {"発注": [{"商品ID": "S01", "数量": 80}, {"商品ID": "S12", "数量": 6}]}
---
播磨ゴールド（350ml×6缶パック）が5日前から在庫0で、酒類の売上が約3割落ちています。土曜の秋祭りに間に合わせるには、今日15時までの発注が最後です。
欠品の前の売れ方（1日 約7パック）×次の入荷まで＋屋台の分で 80パックにしました。地ビールのセットは 6セット。地ビールのセットも同じ仕入先なので一緒に頼みます。
```

## 実行（会社に入れる中身）の書き方

| 種類 | 実行の例 |
|---|---|
| 発注 | `{"発注": [{"商品ID": "D01", "数量": 36}]}` |
| 値下げ | `{"値下げ": [{"商品ID": "F05", "率": 0.1, "日数": 7}]}` |
| 広告 | `{"広告": {"チラシの回数": 1, "Instagram広告": 31000}}` |
| 督促 | `{"督促": {"取引先ID": "C01"}}` |
| 出荷を止める | `{"出荷停止": {"取引先ID": "C01", "止める": true}}` |
| 契約 | `{"契約": {"相手": "あおぞらの家", "内容": "週2回と介護用品の追加を申し出た"}, "法人": {"C05": {"曜日": [0, 3], "1回の目安": 9500}}}` |
| 掲載 | `{"掲載": {"題": "秋祭りに屋台を出します", "出した場所": "サイト・Instagram・店頭のポスター", "行事": "秋祭り"}}` |
| シフト | `{"シフト": {"雨の日の午前の電話番": true}}` または `{"シフト": {"夕方のレジを2人に": true}}` |
| 配達 | `{"配達": {"北地区を午後便にまとめる": true}}` |
| 在庫の表示 | `{"在庫連動": true}` |
| お酒の表示 | `{"表示": {"G02": "○"}}` |
| 口コミの返信 | `{"返信": "全部"}`（返信の文は本文に書く） |
| 商品ページ | `{"ページ改善": true}` |

`実行` は1行の JSON（ダブルクォート）。発注の `数量` は商品.csv の「単位」で数える（播磨ゴールドの 80 ＝ 80パック）。数字の効果がないもの（例：採用の相談）は `実行` を書かなくてよい（記録だけになる）。
