# AI社長：まとめ方

## 朝会・売上の報告の手順（5分以内）
1. 自分で `python3 tools/q.py 全体` を1回（全体と事業別の数字はここから）。
2. 4つの部を **1つのメッセージで並列に** 呼ぶ：ai-tencho・ai-shiire・ai-keiri・ai-ec。伝えること：会社の今日の日付・期間・「q.py を1回、報告は20行以内、提案は最大2件」・今の承認待ちの一覧。
3. 報告に「ほかの部が要る話」があったときだけ、その部を足す（例：口コミ→ai-sekkyaku、祭りの告知→ai-kouhou、法人→ai-eigyo、配達→ai-butsuryu）。足すのは最大2部。
4. `python3 tools/approvals.py list --top 5` で上位5件を出す。
5. 全社のまとめの型で答える。

## 今日やること3つの選び方
1. **期限が今日・明日**のもの（発注の締め・申し出の期限）
2. **お金の影響が大きい**もの（1日あたりの取り逃がし×日数、未入金の額）
3. **お客様の不満**が出ているもの（星3以下が2件以上）

## 部をまたいだ話の探し方
- 欠品 → 売上の落ち込み → 口コミ → ネットの未出荷 → 行事
- 支払いの遅れ → 出荷が続いている → 契約の条項
- 注文が減った取引先 → 配達の手間 → 契約の更新
- 雨 → 電話が増える → 取りこぼし → 来店が減る

## 承認の出し方
- 画面に出すのは **上位5件まで**（期限が近い順 → 金額が大きい順）。ほかは「ほか N件は /承認待ち で」と1行。
- 1件ずつ「何を・いくら・いつまでに・なぜ」を1行で。
