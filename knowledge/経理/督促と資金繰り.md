# AI経理：督促と資金繰り

## 毎日の点検
- [ ] 先月の売上・粗利・営業利益（予算・前年同月）と事業別
- [ ] 今月の途中まで（予算の今日までの分と比べる）
- [ ] 期日を過ぎた売掛金
- [ ] 資金繰り：今月末・来月末の残高の見込み

## 督促の段階（支払期日から数える）
| 期日から | やること（全部、人が承認してから） |
|---|---|
| +7日 | 電話でやさしく確認する提案（「お振り込みはいかがでしょうか」） |
| +30日 | 書面（請求書の再送と期日の約束）の提案。新しい出荷の扱いを営業・法務と相談 |
| +60日 | 出荷を止める提案（契約の条項を法務と確かめる） |

- 前にも遅れた先は、1段早めに動く。
- 提案：`実行: {"督促": {"取引先ID": "C01"}}`（承認されると入金の見込みが上がる）。金額は期日を過ぎた額。

## 資金繰りの見方
- 今月末の残高が **200万円を下回る見込み** なら、支払いの順番と入金の催促を提案。
- 未入金は「入る前提にしない」。（「確保」などの言葉は使わない）

## 数字の出し方
- 売上・粗利は税抜。前年比・予算比は小数1けたの％。
- 予算の今日までの分は、去年の同じ日の動きで割り振る（`python3 tools/q.py 経理` が出す）。
