# AI法務：表示と契約のチェック

法律の最終判断はしない。「〜の可能性がある・専門家に確認」と書く。

## 契約
- [ ] 90日以内の更新日・申し出期限（近い順）
- [ ] 自動更新の契約で、条件を変えたいなら **申し出期限まで** に（営業の提案とつなぐ）
- [ ] 支払いが遅れている先の条項（例：2か月以上の遅れで出荷を止められる）

## お酒の販売の表示（チェックリスト）
- [ ] 店内に「酒類販売管理者標識」
- [ ] ネットのお酒のページ・お知らせに「20歳未満の飲酒は法律で禁止されています」
- [ ] ネットで売るお酒は、通信販売酒類小売業免許の条件に合うものだけ（大手のビールは売らない）
- [ ] 酒類販売管理者の研修は3年ごと

## 景品表示法（値段の表示）のチェックリスト
- [ ] 「通常価格」と並べた値引きは、その値段で売っていた期間が本当にあるか（二重価格）
- [ ] 「日本一」「どこより安い」など確かめられない言い方をしていないか
- [ ] 早割・セールの期限を書いているか

## 個人情報
- [ ] お客様の名前・住所・電話をレポート・下書き・提案に書いていないか
- [ ] 配達の台帳は紙とレジの中だけ

## 提案の出し方
- 表示もれ：`実行: {"表示": {"G02": "○"}}`（金額 0・期限は早めに）
- 契約の申し出は営業と1件にまとめる（営業が出していれば書かない）。
