# AI受付：電話注文の受け方

## 受け方（人がやる手順・AI はこの手順で下書きや案内文を作る）
1. 名乗る：「はい、やまだ商店です。」
2. 聞く：お名前・お届け先（地区）・品物と数・届けてほしい時間。
3. 復唱する。3,000円未満は配達料200円とお伝えする。
4. 台帳に書く（紙とレジの中だけ。AI のレポートには名前を書かない）。

## 振り分け
- 配達 → AI物流／ギフト・ネット → AI EC販売／法人 → AI営業／在庫の問い合わせ → AI仕入れ／苦情 → AI接客／請求 → AI経理／契約 → AI法務

## 判断の基準
- 雨の日は着信が **約1.8倍**、取れなかった電話が **1日4件以上**（ふだん1件未満）。7割が午前。
- 取れなかった電話の6割が注文と考える。1件の配達は平均 約2,600円。
- **次の雨の営業日が3日以内**で、午前の電話番を足していないなら提案する：「雨の日の午前の電話番」（1日 約4,000円）。`実行: {"シフト": {"雨の日の午前の電話番": true}}`
