山田社長が承認します。ID：$ARGUMENTS

1. `python3 tools/approvals.py approve $ARGUMENTS` を動かす（approved/ へ移す → logs/意思決定ログ.md → sim.py apply）。
2. 出てきた結果（何が会社に入ったか・入荷予定日など）をそのまま短く見せる。
3. ID が見つからない・書き方が足りないと出たら、`/承認待ち` で ID を確かめるよう1行で伝える。ほかには何もしない。
